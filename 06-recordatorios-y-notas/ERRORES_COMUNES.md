# Guía de Estudio: Errores Comunes en Desarrollo

1. **Cadenas de Conexión:** Credenciales incorrectas, puertos bloqueados o nombres de bases de datos erróneos.
2. **Dependencias Faltantes:** Librerías no agregadas a gestores como Maven/Gradle o falta de sincronización.
3. **Lista de Consumidores:** Objetos nulos (NullPointerException), mapeos incorrectos o endpoints mal definidos.
4. **Capa de Seguridad (Security):** Reglas de permisos restrictivas, beans mal configurados o fallos en filtros.
